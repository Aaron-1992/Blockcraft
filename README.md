# Blockcraft

An original Minecraft-Java-1.12-style voxel sandbox for Windows (Java 21 + LWJGL/OpenGL).

* **Play:** download the latest zip from [`releases/`](releases) (small update pack) or use the full
  `Blockcraft-1.12-UPDATE3.5-windows.zip` in the repo root as the base install, extract, run `Blockcraft.exe`.
  Each update pack contains `HOW-TO-INSTALL-THIS-UPDATE.txt`.
* **Develop:** see [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) (build, tests, layout, gotchas) and
  [`docs/PROJECT_STATUS.md`](docs/PROJECT_STATUS.md) (feature list, what is verified, what isn't).

```
python3 tools/build.py --patch     # build the game and the small update pack
python3 tools/runtests.py              # headless tests
```
