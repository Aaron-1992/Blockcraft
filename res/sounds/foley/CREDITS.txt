BLOCKCRAFT V6.29 - REAL RECORDED FOLEY
====================================

The WAV files in this folder are REAL AUDIO RECORDINGS, not tones generated at
run time. They are mono, 22,050 Hz, 16-bit PCM, cut/trimmed, loudness matched
and soft-limited for the game's mixer. Every one is Creative Commons CC0 1.0
(public domain): free for any use, no attribution legally required. No Mojang
code or assets, and no Minecraft audio, is used anywhere in these files.

The files were fetched from two public GitHub mirrors that document each
source recording, its recordist and its CC0 licence. The original recordings
are hosted on Freesound; the mirrors ship the CC0 preview cuts.

  * cyberced21/project-serotonin - audio/gathering/SOURCES.md,
    audio/mine/SOURCES.md, audio/forge/SOURCES.md
    https://github.com/cyberced21/project-serotonin
  * RyanSaxe/gaia - app/renderer/sound/assets/CREDITS.md
    https://github.com/RyanSaxe/gaia

To use your own recordings: replace any WAV in this folder (or in the game's
sounds/foley/ folder next to Blockcraft.exe) with a mono/stereo 16-bit PCM WAV
of the same name, then restart the game or press Reload PNGs. The game reads
the loose WAVs first and falls back to the copies inside blockcraft.jar.
