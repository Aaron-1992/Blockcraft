BLOCKCRAFT V6.12 - MIDI BUILD COMPILER AND NOTE-BLOCK INSTRUMENTS
================================================================

THIS GENERATES A REAL REDSTONE BUILD, NOT A MIDI PLAYER
------------------------------------------------------
Find MIDI Build Compiler in Creative > Decoration and Utility (search MIDI).
It also has a crafting recipe: iron/redstone, quartz/note block/quartz,
iron/redstone, arranged as IRI / QNQ / IRI.
Building requires Creative and the single-player/multiplayer host.
The compiler imports a file, previews its cost, and places ordinary repeaters,
dust, tuned note blocks and the instrument-selecting blocks beneath them.
After building, remove the compiler or delete the MIDI: the BUTTON and REAL
REDSTONE still play the circuit. Break its wiring and playback stops there.

QUICK START - NO COMMANDS OR FILE COPYING REQUIRED
------------------------------------------------
1. Install V6.12. Back up saves before updating.
2. In Creative, place a MIDI Build Compiler and empty-hand right-click it.
3. Browse to your .mid or .midi and click it. Home, Downloads, MIDI folder,
   Drives, Up and page buttons are available; the wheel changes pages.
   Files can stay anywhere you can read them. Spaces, Unicode names and
   uppercase .MID/.MIDI extensions are supported. No renaming required.
4. Selecting a file previews the FIRST FIVE SECONDS by default, not the whole
   song. Edit Start and Length (seconds), then Preview to change the section.
   Tab switches fields; Backspace edits; Enter previews. Nothing is built yet.
5. Read the note/instrument counts, notes outside the section, pitch folding,
   footprint and start-button coordinates. Default height is ABOVE TERRAIN:
   the entire proposed envelope is raised above the highest occupied cell.
   You do not need to put the compiler on a pillar. Nothing is dug away.
6. Click Build circuit. It rechecks the world, compiler, permissions, loaded
   area and every reserved cell before placing anything. You do not need to
   keep the crosshair on the compiler. Moving/removing the file after a
   successful preview does not change the circuit that was previewed.
7. Click Go to button to fly to the start (Creative only), or Close to stay
   where you are. Right-click the physical stone button to play.
   Follow the track to hear distant notes: sound is positional, not global.
   Wait for the pulse to finish (section length + about one second) to replay.

If the preview or build fails, the screen displays the actual reason. Change
Length for an oversized/unloaded track; simplify tracks for a chord over six
notes; re-preview above terrain for occupied space. Changing a field, file or
height setting invalidates the old preview. Escape/Close discards the menu
session, not blocks already built. Import/build is Creative-host-only.

SECTIONS AND OPTIONAL LEGACY COMMANDS
------------------------------------
Start 30 and Length 8 selects note starts from second 30 up to (excluding) 38.
The timing within that window is preserved on the redstone grid. Notes held
from before the window are not synthesized as new note starts.

Each build is a straight track, at most 256 blocks long, in a 16-block-wide,
five-block-high empty envelope. Choose shorter sections if it is too long or
outside loaded chunks. Increase view distance and keep the whole circuit
loaded while playing. This is for short pieces/sections, NOT an unlimited
whole-song/orchestral converter. Maximum selected duration is 120 seconds;
the rail, 512-note or six-note-chord limits can require much shorter sections.

For an original eight-note/four-instrument example, /mididemo creates
Workshop.mid without replacing existing files; open MIDI folder in the picker.
The MIDI folder is %USERPROFILE%\.blockcraft112\midi on Windows or
~/.blockcraft112/midi on Linux. It is optional for the GUI.

Legacy commands remain available: /midi opens the picker when aiming at a
compiler. /midi Workshop.mid previews a simple filename in the MIDI folder;
/midi MySong.mid 30 8 selects a section. /midibuild confirms the last successful
COMMAND preview without requiring the crosshair to remain on the compiler.
GUI previews use the GUI Build circuit button. Command failures now show the
actual MIDI error instead of "Invalid arguments".

HOW THE CONVERSION WORKS
-----------------------
- Standard MIDI file types 0 and 1; PPQ tempo changes across tracks and SMPTE
  timing are supported. MIDI type 2 (independent sequences) is refused.
- Note starts are rounded to 100ms redstone ticks (normally <=50ms error).
  A fixed 100ms startup delay lets the first repeater fire. Repeaters encode
  the timing; no hidden per-song playback scheduler.
- Up to six distinct notes per quantized chord. Chords exceeding that are
  refused, never silently reduced. Identical pitch/instrument duplicates in
  the same chord are merged and reported.
- General MIDI program families are approximated with available note-block
  instruments. Bass, guitar, flute, mallets, bells, chip leads and banjo have
  dedicated mappings; others fall back to harp. Channel 10 maps percussion
  to bass drum, snare and hi-hat. This is not a full GM SoundFont renderer.
- Each instrument has 25 note-block pitches. Out-of-range melodic notes are
  shifted by whole octaves into its range, preserving pitch class. The preview
  reports the number shifted. Drums use the center tuning.
- Note-off, sustain pedal, velocity/dynamics, pitch bend and aftertouch are
  not reproduced: ordinary note blocks make fixed-decay strikes.
- Files <=1 MiB, <=100,000 MIDI events, <=512 selected notes, <=120 seconds
  per selected window, plus the physical 256-block track limit. Dense pieces
  generally require much shorter windows. Invalid/oversized input is refused.
- A failed new preview clears the old pending confirmation. A preview isn't
  saved across quitting; generated blocks and their tuning ARE saved.

NOTE-BLOCK INSTRUMENTS
---------------------
The block directly BELOW a normal Note Block now selects its sound:

  Default / dirt / grass          Harp / piano-like pluck
  Wood-family blocks              Bass
  Sand / gravel / concrete powder Snare
  Glass / stained glass           Hi-hat
  Stone-family blocks             Bass drum
  Clay                            Flute
  Gold block                      Bell
  Wool (all colors)               Guitar
  Packed ice                      Chime
  Bone block                      Xylophone
  Iron block                      Iron xylophone
  Soul sand                       Cowbell
  Pumpkin / carved pumpkin        Didgeridoo
  Emerald block                   Bit / chip lead
  Hay bale                        Banjo
  Glowstone                       Pling

The specific material rules take precedence over wood/stone families.
All 16 waveforms are locally synthesized; no external instrument recording
or MIDI synthesizer/device is required. Harp range is F#3..F#5 (MIDI 54..78);
bass/didgeridoo start two octaves lower, guitar one lower, flute/cowbell one
higher, bell/chime/xylophone two higher. Other pitched voices use harp range.

Right-click to tune through 0..24; the instrument and pitch are shown in chat.
A solid block OR any other block occupying the cell directly above silences
playback. Redstone triggers on the rising edge, not repeatedly while held high.
Changing the material underneath changes the timbre on the next strike.
Tuning survives save/load and piston moves. Breaking/replacing a note block
resets it to pitch 0. Keep notes.properties with the rest of the world backup;
older game versions do not understand this saved tuning. Corrupt tuning files
are preserved and block new compiler builds rather than being overwritten.

MULTIPLAYER AND LIMITS
---------------------
Everyone should use V6.12. Only the host imports/builds and tunes note blocks.
Host note events carry the actual instrument/pitch to clients; clients do not
need the MIDI file. Playback is still local/positional, with network latency.
No real two-computer/device audition is claimed by automated checks.

Existing Shadow Signal, Block Drop, display hardware, textures, flat sprite
bow and held lighting are retained. This update does not replace your worlds.
