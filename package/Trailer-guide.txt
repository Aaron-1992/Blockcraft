BLOCKCRAFT V6.31 - THE ONE-MINUTE IN-GAME CINEMATIC TRAILER
===========================================================

HOW TO WATCH
  * Title screen: press "Watch Trailer (1:00)".
  * While playing: type /trailer in chat.
  * It runs for exactly 60 seconds and then returns automatically.
  * ANY KEY or a mouse click skips it immediately.
  * Everything is restored afterwards: your screen, camera position,
    view mode, daylight, weather, colour grading and options.

THIS IS A MONTAGE, NOT A VIDEO OR ONE LONG FLYTHROUGH
  No movie file is shipped. V6.31 replaced the single continuous
  camera with 24 hard cuts in 60 seconds:
    8 different camera moves - Glide, Dolly, Orbit, Crane, Dive,
      Static pan, Top-down, Chase
    8 different locations in a real freshly generated world
    a cut-up dawn / noon / storm / sunset / night / dawn arc
    big word cards, 0.14 s cut flashes, a four-act soundtrack
    foley stings from the real CC0 WAVs in sounds/foley/
    the block-built BLOCKCRAFT logo finale
  It is drawn by the game's own renderer with the same chunks,
  trees, caves, sky, weather and shaders as normal play.

SHOT PLAN (2.0-5.5 s per cut, total exactly 60 s)
  Print the deterministic list with no window or GPU:
      java -jar blockcraft.jar --trailer-plan
  See docs/releases/v6.31-trailer-plan.txt and the headless
  storyboard docs/screenshots/v6.31-trailer.png (NOT a GPU shot).
  Source: src/bc/Trailer.java. Notes: docs/releases/v6.31.md.

No Mojang code or assets are used anywhere in Blockcraft.
