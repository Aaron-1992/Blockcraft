# V6.29 — normal walk-in cave entrances, real recorded sounds

The user rejected V6.28 twice: *"still no normal cave entrances"* and
*"use real sounds not generated ones"*. This release addresses both. No
Mojang code or assets are introduced.

## Normal cave entrances (`caveVer = 4`, new worlds only)

`CaveCliffs.Mouth` now has two implementations. `ver = 3` keeps V6.28's
sloped crack **byte-for-byte** for worlds created with V6.28; `ver = 4`
is the new walk-in entrance used by worlds created in V6.29.

A V6.29 mouth is a hashed site on a 64-block cell grid (~70 % of cells, and
all nine cells around the world spawn), placed only where the whole rim is
dry land at `h >= 64`. It is made of:

* a **wide irregular round opening** (radius 6–10, stone lip) in the surface;
* a **solid, gently sloping floor** from one block under the grass at the
  downhill lip down 14–20 blocks at the uphill end — you walk in, you do not
  fall down a 45-block diagonal crack;
* a **rock arch** over the deep end (`u > 0.70` keeps a three-block roof);
* a **rounded chamber**, a **horizontal gallery**, a **shaft** and a
  **straight 2.8-block tunnel** whose far end is placed on a block that
  `CaveCliffs.carve()` really hollows, so the entrance is a way *into* the
  cave network rather than a dead-end pit;
* `TerraGen` keeps the ramp blocks solid (noise caves cannot hollow the floor
  out from under the player), keeps trees and spawn out of openings, and
  switches the old noise sinkholes / vertical shafts off. Ravines are reduced
  further (`need = 0.30`) so the surface is not covered in endless cracks.

All answers are pure functions of seed and coordinates; the expensive
per-cell site/link search is cached in a `ConcurrentHashMap`, so worker
threads and chunk seams agree. Old saves keep the `caveVer` they were created
with.

Headless verification at seed `20261107`: 47 distinct mouths within 320
blocks of spawn, 7 within 200, **47/47 continuous surface → ramp → chamber →
tunnel → real carved cave**. The chosen sample has 208 open surface columns
with a 16×17-block hole and a ramp whose solid floor steps 1→11 blocks down
over 14 blocks. `docs/screenshots/v6.29-caves.png` shows the V6.28 diagonal
crack, the V6.29 bowl/arch/gallery cross-section and a top-down view of the
round mouth with its stone lip. It is a headless generated image, not a GPU
screenshot.

## Real sounds, not generated ones

The eight procedural tones added in V6.28 were **deleted** from
`SoundEngine.synthesizeAcousticSupplements()`. Ten world cues are now real
CC0 1.0 field/foley recordings, trimmed, loudness-matched and stored as
22,050 Hz mono 16-bit WAVs under `res/sounds/foley/`:

| Key | Recording | Recordist |
| --- | --- | --- |
| `tree_fall`, `tree_crash` | "timber tree falling 1" (fall / landing halves) | matt_beer |
| `tree_creak` | "knakande träd 1 (creaking tree)" | Ryding |
| `leaf_rustle` | "Forest, close up of trees rustling in the wind" | Anya_Media |
| `wind_gust` | "Wind gusts grass" | fran_marenco |
| `cave_drip` | "Water Dripping (Large Echo)" | editor_adp |
| `cave_wind` | "archi_soundscape_cavern3" | ElanHickler |
| `cave_rumble` | "Cinematic Deep Bass Rumble" | mmasonghi |
| `geode_chime` | "Crystal glass (pitch E) 2 long sustains" | esoonchia |
| `stone_crumble` | "RockFall1b.wav" | AlanCat |

Sources and exact links are in `res/sounds/foley/CREDITS.txt` (also shipped
as `sounds/foley/CREDITS.txt` in the game folder). The recordings were
mirrored by two public GitHub projects that document each Freesound source
and CC0 licence: `cyberced21/project-serotonin` and `RyanSaxe/gaia`.

`SoundEngine` now contains a dependency-free RIFF/WAVE PCM decoder
(8/16/24/32-bit, mono/stereo, linear resampling). `loadRecordedFoley()`
looks for loose WAVs in `sounds/foley/` first, then `res/sounds/foley/`,
then the jar resource; a player can replace any recording without
rebuilding. `recordedFoleyCount()` / `isRecordedFoley()` expose the state to
tests and diagnostics, and the in-game `/sounds` command reports how many
WAVs are active and plays one (`/sounds tree_crash`) so it can be checked
without leaving the game. `Game.caveAmbience()` also picks `wind_gust` now.
The End Credits gained a real-foley section.

The WAVs are shipped **twice**: loose next to the exe (editable) and inside
`blockcraft.jar` (fallback). `tools/verify_release.py` checks both copies are
byte-identical to the source files for V6.29+.
