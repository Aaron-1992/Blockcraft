# V6.11: MIDI Build Compiler and material-selected note instruments

## Implemented

A craftable/Creative **MIDI Build Compiler** imports local standard MIDI type 0/1 files, previews the exact block cost/clearance and conversion warnings, then generates **ordinary repeaters, dust, tuned note blocks and instrument substrates** on explicit confirmation. No MIDI sequencer runs during playback. Removing the compiler/file does not stop the generated circuit; breaking a required repeater does.

The parser handles merged-track tempo maps, PPQ and SMPTE, program-family mapping and channel-10 percussion. Conversion is explicitly approximate: 100ms timing plus 100ms lead-in, at most six distinct notes per chord, octave folding, fixed-decay strikes (no velocity/sustain/bend reproduction). Files are bounded; oversized chords/tracks are refused, not silently discarded. Long files can be selected by start/duration. Physical tracks are limited to 256 blocks and must stay loaded. This is for short pieces/sections, not an unlimited full-song orchestral converter.

Sixteen synthesized note instruments respond to the supporting material. Tuning is now saved in `notes.properties`, preserved through piston moves, and removed when a block is broken. Occupied space above mutes playback. Host-authoritative note audio packets carry instrument/pitch, without transmitting MIDI files. Corrupt tuning maps are preserved and prevent new compiler builds.

Full player guide: [MIDI-guide.txt](../../package/MIDI-guide.txt). The original `Workshop.mid` example is generated by `/mididemo`, without replacing an existing file.

## Limits and provenance

All new instrument waveforms and the four-second demo are generated locally; no external music/samples were fetched. Automated PCM/bank/packet checks are not a physical-device or two-PC audition. Sounds remain positional, so follow long tracks and keep chunks loaded. The compiler is Creative-host only; multiplayer tuning is host-only. Existing V6.10 cinema/arcade hardware, textures, sprite bow and held lighting remain.
