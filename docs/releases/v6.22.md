# V6.22 — Caves & Cliffs carver, cheaper taiga, smoother borders, live shadows, movable minimap

This update answers five complaints in one pass: taiga / spruce biomes being "the game's
Death", mob shadows that only moved when the terrain shadow map refreshed, caves that were
"still not really good", a world that needed a broader generation overhaul with smoother
biome borders, and a minimap that sat on top of achievement toasts.

**Everything here is new-world generation or a runtime setting; old saves keep their exact
V6.21 terrain.** No Mojang code or assets were used — the Caves & Cliffs *style* is an
original implementation in this repository.

## 1. Caves & Cliffs-style underground (`src/bc/CaveCliffs.java`)

`WorldSettings.caveVer` selects the carver: `1` = V6.21 layered tunnels (old saves),
`2` = the new engine (new worlds, toggle **Caves & Cliffs** in Debug Video > Advanced).
`CaveWorks.hollowCC()` forwards to a carver that is a pure function of `(seed, x, y, z)`
so chunk seams and worker threads always agree.

| Shape | What it does |
|---|---|
| Noodle caves | Thin twisty tunnels just under the surface, from a ridged 3D noise pair. |
| Spaghetti caves | Long winding tunnels through the middle depths at a larger scale. |
| Cheese caves | Big irregular low caverns in coherent slow-noise provinces. |
| Halls, wells | Sparse hashed ellipsoids and vertical connections between layers. |
| Aquifers | A hashed **local** water table per 64×64 region (38% of regions, y = 22..49). Carved space below it is water, so one cavern is dry on top and flooded at the bottom. |
| Lava provinces | Lava only at the very bottom, in coherent provinces. |
| Cave biomes | Warped 128-block provinces: lush, dripstone, ice, amethyst, deep dark and plain. |
| Content | Amethyst geodes (obsidian/calcite/purpur shells with crystal buds), hanging vines, glow berries, spore blossoms, moss/azalea, dripstone, clay and lily pads over aquifers, exposed ores and deep-dark floors. |

`finish()` decorates only a chunk's inner columns, so decorations cannot mismatch at
seams. The V6.21 underground site types (ruined shrine, crystal geode, lava forge,
mineshaft hall, mushroom grotto, flooded cistern) still run on top of the new carver,
so deep worlds keep their structures and loot. `docs/screenshots/v6.22-caves.png` is a
headless cross-section of the **real generator**, not a GPU screenshot.

## 2. Taiga / spruce no longer the heaviest chunks

The old `TerraTrees.classic(sp = 2)` filled every cell of every level of a cone up to
radius 4 — roughly a thousand leaf blocks per spruce. `megaSpruce` did the same over 24
levels at radius up to 6. V6.22 rebuilds both as **tiered conifers**: a hairline every two
blocks, a hollow interior, drooping branch tips and gaps between tiers.

Measured on the headless 3×3 taiga probe at seed 6120 (bushy leaves on):

| | V6.21 | V6.22 |
|---|---|---|
| spruce leaf blocks | 593 | 297 |
| mesh vertices | 199,744 | 165,648 |
| mesh time (warm) | 62.9 ms | 36.2 ms |

Tree density in taiga, snowy taiga, mega taiga, dark forest and jungle was reduced; a
per-chunk cap (`30 × Tree Density`) prevents any biome from producing a mesh-time spike;
and `Mesher.bushyFronds` no longer allocates a temporary `int[]` twelve times per leaf
block. **Tree Density** (0.4×–1.4×) is a new slider, copied into the world at creation.
These numbers are headless meshing timings, not FPS claims.

## 3. Smoother borders and a broader world-gen overhaul

`WorldSettings.biomeBorders` = 0 (legacy, sharp) / 1 (smooth) / 2 (very smooth), exposed
as **Biome Borders** in Debug Video > Advanced.

- Two slow noises **warp the climate coordinates**, so biome edges meander instead of
  following straight contour lines.
- Around every climate threshold a border band is computed (`TerraGen.climateEdge`), with
  the neighbouring biome identified by probing `pick()` on either side. Within that band:
  surface blocks (sand / grass / podzol / snow), flowers, grass and tree species **interleave
  deterministically** instead of flipping at one line; tree density fades out; special biome
  tints fade out; and preview / minimap colours blend toward the neighbour.
- **Mountain terraces** give soft seven-block shelves on high peaks instead of a smooth cone.
- **River valleys** broaden into gently sloping banks instead of a knife-edge trench.
- **Shorelines** flatten into wider beaches, and the snow line is broken by ±7 blocks of
  deterministic jitter.
- `WorldPreview` applies a 3×3 colour blur to the biome map when smoothing is on; `MapView`
  blends unloaded columns toward their neighbour biome.

`docs/screenshots/v6.22-borders.png` shows the same 1080×720 block area with the two
settings, using the in-game world-preview palette.

## 4. Entity shadows update every frame

Previously mob silhouettes were drawn once into the terrain shadow map and only moved when
that map refreshed (every 8–150 frames). `Shaders` now keeps a second, **terrain-only**
depth target. Every frame `Renderer.updateEntityShadows()`:

1. restores the terrain-only depth with one `glBlitFramebuffer` depth copy,
2. re-stamps the current mob silhouettes into the working shadow map in a depth-only pass,
3. restores the scene framebuffer.

No terrain geometry is re-rendered, so shadows follow every mob every frame at a fraction
of the cost of a full shadow refresh. **Live Entity Shadows** can be turned off in
Debug Video > Advanced for the old behaviour. The terrain refresh gate, sun/moon light and
`Perf.shadowEvery` override are unchanged.

## 5. Minimap positions and achievement-toast avoidance

`Options.minimapPos` adds four HUD corners: top right (default), top left, bottom right,
bottom left. **Minimap Position** cycles them in Debug Video > Advanced; the position is
saved in `options.txt`. `MapView.miniOrigin()` is pure and unit-tested.

`Options.minimapAutoMove` (**Move for Toasts**) slides a top-right minimap 38 GUI units
down while `Adv312` is showing an advancement toast, so the toast is never covered. Other
corners are already clear of the toast and do not move. Both maps, rotation, size, radius,
mob dots and grid are unchanged.

## 6. Settings, UI and compatibility

New `Options` fields: `caveCliffs`, `biomeBorders`, `treeDensity`, `minimapPos`,
`minimapAutoMove`, `entityShadowMotion` — all persisted with clamping.
New `WorldSettings` fields: `caveVer` (1..2), `biomeBorders` (0..2), `treeDensity`
(0.4..1.4) — all saved/loaded with old-save defaults of 1 / 0 / 1.0.
`Screens.applyNewWorldSettings` copies them into new worlds; `WorldPreview` includes them
in its cache key so the Create New World preview reacts immediately.
`ADV_ROWS` grows from 57 to 60 for the three new Advanced rows.
