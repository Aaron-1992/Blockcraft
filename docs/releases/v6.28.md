# V6.28 — 1.20-style caves, real entrances, more sounds

## Caves (`caveVer = 3`, new worlds only)

`CaveCliffs` keeps the four 1.18 carver shapes but makes them substantially
bigger and better connected:

* **Cheese caverns** now span `y = 8..72` (was `8..46`) and use **two**
  overlapping large-scale noise fields with a lower gate, producing the
  multi-room chambers of 1.18/1.20 instead of one sealed pocket.
* A **third, very long spaghetti tunnel scale** (`0.008` blocks⁻¹) joins
  separate pockets into continuous systems; the mid-depth tunnels are also
  ~35 % wider.
* Headless 6×6-chunk scan at seed 20261107: `caveVer 2` = 32,490 air /
  873 water / 392 lava; `caveVer 3` = **52,790 air / 1,335 water / 739 lava**
  (+62 % carved volume). Local hashed aquifers, lush / dripstone / ice /
  amethyst / deep-dark biomes and geode shells are unchanged.

## Real cave entrances

The user's "infinite cracks in the ground" were ravines and small vertical
sinkholes. `CaveCliffs.Mouth` adds deterministic **actual entrances**:

* ~53 % of 96-block hash cells get a site with a 4–8-block radius, a hashed
  descent direction and a hashed surface height gate (`h >= 66`).
* A visible **surface opening** with an irregular edge and a **stone lip**
  (`Mouth.rim`), so it reads as a cave mouth rather than a random hole.
* A **shallow sloped ramp** (horizontal drift = 1.05 × vertical drop) down
  from `h-3` to `max(26, h-46)` — walkable-looking, not a vertical crack.
* A **rounded bottom chamber** and a **low horizontal gallery** that runs
  out into the surrounding cave network, so the entrance is never a dead end.
* `CaveWorks.mouthSurface()` keeps trees and the world spawn out of openings;
  `TerraGen.generate()` carves the mouths with the per-column surface height,
  which is a pure function of the seed and coordinates (chunk seams agree).

Headless verification: 63 sampled entrances (and all 275 in the wider sample)
were continuous from surface → ramp → chamber → gallery.
`docs/screenshots/v6.28-caves.png` shows the old carver above and the new
entrance below in a real generated cross-section. Old saves keep their
`caveVer` and are untouched.

## More sounds

Eight new **procedurally synthesized** samples (no Mojang / third-party
audio) in `SoundEngine.synthesizeAcousticSupplements()`:

| Key | Where it plays |
| --- | --- |
| `tree_fall` | `Trees.launch()` — wooden creak + rising canopy whoosh, audible to 48 blocks |
| `tree_crash` | `Trees.land()` — low thud, wood crack, settling leaves |
| `leaf_rustle` | `SoundEngine.playBlockBreak()` for leaves (1 in 4) |
| `cave_drip` | cave ambience, two resonant droplets + echo |
| `cave_wind` | cave ambience, slow low-passed air swells |
| `cave_rumble` | cave ambience, subterranean 34 Hz swell |
| `geode_chime` | cave ambience, amethyst bell |
| `stone_crumble` | cave ambience, tumbling gravel |

Aliases: `tree_creak`, `water_drip`, `cave_ambience`.
`Game.caveAmbience()` fires occasionally while the player is under a rock
ceiling between y=8 and y=54, positional 3–13 blocks away, using the
existing spatial/acoustic mixer.
