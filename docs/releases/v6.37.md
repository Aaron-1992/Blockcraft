# V6.37 — Minecraft-style menus, lifted skies, sections above y=255, clean shader toggles

The V6.35 "Atlas" UI and the V6.36 plain-panel UI were both rejected. The user
said: *"renderings completely fucked Ui still looks like shit keep it like
minecraft but better / Clouds and stuff are completely offset now and Normal
chunks dont render above original height / When activating shader it has like
burn in where you have to look at the ground and then turn it on so it doesn't
appear also happens when chanign effects quality also effects should still be
editable and shader should still be able to be put to fancy from normal
settings"*.

## Menus: like Minecraft, but better

`Menus635.shell()` no longer draws a framed panel, a nav rail, numbered cards or
cyan kickers. It dims the turning panorama / the paused world by 30%, draws dark
bands at the top and bottom, prints a plain title and puts menu buttons in the
classic **centred 200-unit column**. Forms, world lists and settings use the full
width; action rows are up to 400 units wide so no label is clipped ("Save and Quit
to Title", "Create New World"). The footer is quiet: `Blockcraft V6.37` on the
left and `Original game - not Mojang` on the right.

Kept from V6.36, because the user asked for it: **every setting prints its real
value** (`Render Distance: 8 chunks`, `70 degrees` in gold, `Depth: 384 blocks`,
`VSync: ON`), full mini-game names, `Reset to defaults`, obvious `Back`, and the
**live world-map preview on Create New World** with biome count, seed and the
world's real depth.

## Shaders and effects in normal Settings

The ordinary Video tab now has:

* `Shaders: OFF / ON / FANCY` — FANCY turns the shader pack on *and* sets
  `waterQ = 2` (the water mirrors the land). It used to be reachable only from
  Graphics / Advanced.
* `Effects: LOW / MEDIUM / HIGH` — the effects quality is still editable from the
  same tab instead of only behind Debug Video.

Debug Advanced still exposes all 61 video / shader / LOD / performance controls.

## No burn-in when shaders or effects change

`Shaders.optionSignature()` watches every graphics option. `Game.render()` calls
`Shaders.syncOptions()` before the scene begins; any change calls
`invalidate()`, which clears the **scene, six bloom, AO, ray, cloud, copy,
cloud-shadow and both depth-only shadow targets**, drops the stale shadow maps
and forces a resize. Freshly allocated FBO textures are cleared as well, so the
first shader frame after toggling Shaders or changing Effects can no longer
composite a ghost of uninitialised memory. No looking at the ground required.

## Clouds, weather and "stuff" are no longer offset

V6.35 lifted the sea level from 63 to 191 but several renderers still used the
classic absolute Y values. V6.37 lifts all of them together:

| What | Before | Now |
| --- | --- | --- |
| Plain blocky clouds | y=130 (108 for Infdev) | `130/108 + Gen.depth()` |
| CPU cloud mesh / rain curtains | y=168 / 146 | `Weather.baseAlt(storm, world.settings.depth)` |
| Raymarched cloud shader | `mix(168, 146, storm)` | `+ cloudLift` (new uniform, set in `weatherUniforms`) |
| Cloud slab | 140..252 | `lift + 164..250+134·core` |
| Cloud-shadow plane | y=64 | `Gen.SEA + 1` |
| Lightning tops / ground fallback | y=168 / 64 | lifted |
| Sun visibility, sky gloom | 168 | `168 + lift` |

## Normal chunks now render above the original height

`CaveCull.Walk` still indexed 16 vertical sections, so every section from
y=256 to y=383 was invisible; `Renderer` also clamped the camera's section and
its visible/shadow loops to 16, and `LodMap` / `MapView` started their scans at
y=255. All of them now use `Chunk.SECTIONS` / `Chunk.H`. Eight gameplay systems
(fire, trees, shapes, disasters, mobs, redstone, the all-blocks gallery and
SkyGen) had the same 256 ceiling and now use the real world height. The
distributed V6.10 sound worlds still load unchanged: the saved `World.pack`
was **not** touched.
