## Limits (not hidden by test totals)

* No physical speaker/device audition or real two-PC multiplayer test is claimed. Tests mix actual PCM and exercise actual packet dispatch without an audio device.
* Audio never consumes beyond the submitted movie frame. A bounded frame/device-block buffer (under 62ms) prevents periodic device-block boundary gaps. Hardware buffering, renderer uploads, real-lamp afterglow and network latency still add delay; stalled simulation can stutter/hold audio.
* Ordinary lamps retain four-tick off delay. The 64×48 panel display is sharper than the 2×-sampled 32×24 lamp wall. Geometry merging preserves pixels, but this does not promise unlimited-machine performance.
* Keep the host near the machine so chunks remain loaded. Custom media is copied separately to clients; the original clip is already bundled everywhere.
* `/arcadesound` only recognizes exact supplied bytecode and **resets the game**; it does not silently replace custom ROMs. Both new saves use different folders and a non-overwriting installer. V6.9 downloads remain unchanged.
* Original animation includes occasional high-contrast scene cuts; no claim of flicker-free suitability for every viewer.
