# V6.24 — proper 3D trees, matching LOD and clean entity shadows

V6.23 was rejected visually: its crowns were flat one-block plates with random
holes, distant LOD tiles drew an unrelated decorative forest, and mobs cast
opaque rectangular boxes. V6.24 fixes all three and sweeps the related bugs.

## Trees

* `TerraTrees.crown()` builds a closed, gently irregular 3D canopy shell with
  solid top/bottom caps. `blob()` now uses it; the old code randomly removed
  38% of the outer cells, which left the crowns looking like swiss cheese.
* `TerraTrees.dome()` replaces every stacked-`disc()` group with **one**
  coherent canopy from a vertical radius profile. Stacking independent domes
  overlapped half-shells and exhausted the leaf budget, truncating the biggest
  jungle trees mid-crown.
* `spruceShape()` is a continuous conical shell with soft tiering instead of
  isolated one-block rings separated by 2–3 blocks of air. The tip is closed.
* The `disc()` loop was asymmetric (`dx <= ir + 1`); it is gone entirely.
* Jungle giant side lobes now join the main crown; the birch clump's detached
  top puff is attached; acacia and dark-oak canopies have real thickness.
* Headless worst case over all 102 species/variant/tier combinations, including
  Tree Size 1.5×: **938 leaves of the 1200 budget — zero truncations**. The
  shells also cut meshing work versus V6.23's solid overlapping domes.

See `docs/screenshots/v6.24-trees-and-lod.png`: left column is the real voxel
geometry, right column is the silhouette the LOD tiles draw. Both are headless
renders, not GPU screenshots.

## LOD

* `TerraGen.treeAttemptSeed()`, `TREE_ATTEMPTS`, `treeDensityAt()` and a static
  `treePlan()` are now shared. `Lod.trees()` replays the **exact** 44-attempt
  chunk dice the generator rolls, then uses `treeVariant()` / `treeSizeTier()`
  so a distant tree is the same species, silhouette and size tier as the real
  one at the same coordinate.
* `TerraTrees.LodShape` is measured once at start-up from the actual tree
  geometry: trunk height, crown bottom/top and a six-band radius profile.
  `Lod.lodTree()` draws those bands, so umbrellas stay flat, conifers taper
  and giants are taller. 100 distinct silhouette signatures.
* Distant chunk decimation uses a hash (`chunkKeep`) instead of a fixed stride,
  removing the empty stripes in far forests, with a per-tile box budget.
* Mushrooms, ice spikes and desert cacti keep their special silhouettes;
  the `LodMap` "trunk was felled" check, village/landmark suppression and the
  height/biome grid fast path are all preserved.

## Entity shadows

* One **soft radial billboard** per mob replaces five opaque cuboid faces.
  `Shaders.makeShadowBlob()` creates a 32×32 feathered alpha mask; the entity
  pass sets `solid=0` so `DEPTH_FS` discards outside the ellipse.
* **Root cause of the drift:** the shadow matrix (`clipM`) is built at the last
  shadow refresh, but mob silhouettes were drawn relative to the *live*
  camera. Between refreshes the camera can move up to 12 blocks, so shadows
  slid away from their mobs. Casters now use `sh.mapX/Y/Z` and `mapSx/Sy/Sz`.
* The entity-only pass no longer applies polygon offset (which pushed the
  billboard's depth away from the light).
* With **Live Entity Shadows** off, mobs are stamped once per shadow refresh
  instead of getting no shadows at all. With it on they still update every
  frame from the terrain-only depth copy.

## Bug sweep

Fixed: lopsided disc loop, hole-riddled crown shells, flat canopies, ring-gap
spruces, conifer tip gaps, leaf-budget truncation, detached jungle lobes,
clipped birch crowns, LOD's independent tree placement and fixed-stride
stripes, missing static mob shadows, drifting mob shadows, opaque box shadows.
