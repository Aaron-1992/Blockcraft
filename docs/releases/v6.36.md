# V6.36 — plain menus, and settings that show their numbers

The user rejected the V6.35 UI: *"Dont like ui at all also settings dont even show numbers and half
the stuff does not make any sense"*. This release replaces that interface completely. The 384-block
deep worlds, depth-scaled caves and twelve integrated structures from V6.35 are unchanged.

## The "Atlas" UI is gone

V6.35's dark navigation rail, numbered glass cards, cyan kickers, duplicated card titles, clipped
abbreviations (`Worl~`, `Graphi~`) and `DEEP WORLD / 384 BLOCKS / ESC = BACK` footer were all
removed. `Menus635.java` was rewritten as an ordinary interface:

* one centred panel per screen, drawn over the dimmed world/panorama;
* a plain title, a thin rule and one short subtitle;
* a simple list of clearly labelled buttons;
* an obvious **Back** button on every screen;
* a footer that is only `Blockcraft V6.36 - original, not Mojang`.

No decorative numbering, no `OPEN` buttons duplicating a card title, no two-letter abbreviations.
All sixteen menu screens still route through the same `Ui` widgets, so clicks, keyboard focus,
scrolling, hints and toasts behave exactly as before.

## Every setting prints its real value

Settings were rebuilt around three row types, all of which put the current value **in the label**:

| Row | Example |
| --- | --- |
| Stepped number (+ unit) | `Render Distance: 8 chunks`, `Max FPS: 0 fps (0 = unlimited)`, `GUI Scale: 0 (0 = automatic)`, `World Depth: 384 blocks` |
| Slider | name on the left, `70 degrees` in gold on the right, **and** `70 degrees` inside the bar |
| Toggle | `VSync: ON`, `3D Cave Volumes: ON` |
| Named choice | `Minimap Corner: Top right`, `Bloom: Full`, `Leaves Quality: Fancy` |

Numeric sliders print two decimals for float values and whole numbers for integer ones. The
**Debug Advanced** tab still calls `Screens.advancedTab`, so all 61 render, shader, LOD and
performance switches remain configurable in game — their labels are clipped to fit the plain
panel. "Reset to defaults" now says exactly what it resets.

## "Half the stuff does not make any sense"

Labels were audited and rewritten:

| Before | Now |
| --- | --- |
| `Brawl`, `Tumbl`, `Beds`, `Murdr`, `End` | `Battle`, `Tumble`, `Bedwars`, `Murder`, `Ender` |
| `TR / TL / BR / BL` | `Top right / Top left / Bottom right / Bottom left` |
| `Dodge Toasts` | `Move Minimap For Pop-ups` |
| `GFX`, `Adv`, `Arena Maps / Brawl` | full words |
| `Preset`, `Type`, `Mode` | `Flat Preset`, `World Type`, `Game Mode` |
| `Deep World: ON` (no number) | `World Depth: 384 blocks` |
| `Reset` | `Reset to defaults` |
| `01 / WORLD`, `02 / LIVE WORLD MAP` | `WORLD`, `WORLD MAP` |

The **live world-map preview on Create New World is kept** — the user liked the map, not the old
menu around it. It is the same `WorldPreview` widget in a plain two-column form, with the biome
count (`Biomes: 33 of 33`) and the seed shown as numbers, and it still previews the real depth of
the world that will be created.
