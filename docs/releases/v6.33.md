# V6.33 — every menu redone

The user asked: *"Redo all menus i want Singleplayer multiplayer and settings on the main screen / when pressing single player you can choose between minigames and open world or whatever / In multiplayer the same thing but with actual name and stuff and more like single player world creation / On minigames it should also look better / Settings should have more tabs so you dont have to search as much"*.

## Main screen

`Screens.title()` is now **exactly three big choices**: Singleplayer, Multiplayer and
Settings. The one-minute trailer and Quit moved to small footer buttons; the version,
texture-pack line and "Not affiliated with Mojang" moved into a compact footer. The
logo, splash and subtitle are unchanged, and the subtitle/splash are now clamped so
they stay on screen at every window size.

## Singleplayer hub (`Game.S.SP_HUB`)

Pressing Singleplayer opens a new card-based hub:

* **Open World** → the saved-world list / Create New World (unchanged behaviour).
* **Mini Games** → the Console Edition mini games hub.
* **All Blocks Gallery** shortcut and a **Back** button.

Each mode is a coloured card with a title, a one-line description and its own **Play**
button, instead of another list of identical grey buttons.

## Multiplayer hub (`Game.S.MP_HUB`) and creation (`Game.S.MP_CREATE`)

Multiplayer gets the same two choices, plus the "actual name and stuff":

* **Open World** → the full multiplayer connection screen (server address, LAN, Share
  Code, world-wide tunnel, host, nick — all preserved).
* **Mini Games** → the mini games hub with `mgReturn = MP_HUB`.
* **Create & Host World** → a new **Create Multiplayer World** screen laid out like
  Create New World: **World Name**, **Seed**, **Player Name**, **Game Mode**,
  **World Type**, **Structures**, **Bonus Chest** and a **live biome preview**. The
  bottom **Create & Host** button copies those values into `Net319.mpWorldType`,
  `mpGameMode`, `mpWorldName`, `mpSeed` and the nickname, then hosts the world; the
  hosted world actually displays the chosen name and uses the chosen seed.
* A **Server Address / Share Code** field with a **Join** button, and **Back**.

Typing, backspace, copy/paste and up/down focus cycling work in all three fields
(`Game.onChar` / `Game.onKey` gained `MP_CREATE` handling).

## Mini Games hub

`Screens.minigames()` keeps every existing feature (seven mode tabs, eight arena maps,
kits, bots, music, Play Now, Open Lobby) but now looks like a proper hub:

* a gold header rule and two dark card backgrounds with a divider;
* **ARENA MAPS / <mode>** section label;
* a **gold frame around the selected arena** so the choice is obvious;
* a framed **live preview** and a **<mode> - <map>** banner;
* a gold highlight behind **Play Now**.

## Settings: more tabs, less searching

`TABS` grew from 4 to **7**: Video, Graphics, Gameplay, Controls, **Sound**, **World**,
**Content**; Debug Video still unlocks the eighth **Advanced** tab. Tabs are drawn in
**two rows of four** so every label stays readable even in a 320×240 window, and the
content area starts below both rows.

* **Sound** — sound volume, music volume, 3D acoustics, constant music, next track and
  the real-CC0-foley count.
* **World** — new terrain, Caves & Cliffs (`caveVer 6`), biome borders, tree density,
  giant trees, cave structures / layers / lakes, cave scale and cave amount. These
  generation controls used to be buried in the Advanced tab.
* **Content** — Skins, Resource Packs, Mods, Credits, More..., the trailer, the All
  Blocks gallery and Reload Tilesheet.
* **Advanced** (`Screens.ADV_TAB = 7`) — all 61 render/shader/performance rows, unchanged.

The older `More...` screen is still reachable from the Content tab, so Skins / Packs /
Mods / Credits / Mini Games / gallery remain one click away from everywhere.
